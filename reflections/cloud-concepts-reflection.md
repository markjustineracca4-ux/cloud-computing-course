# Cloud Computing Concepts & Version Control Reflection

## Cloud Services in Daily Use

In my daily routine as an IT student, cloud computing plays a crucial role in my productivity, communication, and visual management. Three cloud platforms I regularly rely on include:

1. **Google Drive**
   - **Service Model:** Software as a Service (SaaS)
   - **Deployment Model:** Public Cloud
   - **Justification:** Google Drive provides fully hosted, end-user cloud storage accessible directly via web browsers and mobile devices without requiring infrastructure management. It operates on a public infrastructure owned and maintained entirely by Google.

2. **Canva**
   - **Service Model:** Software as a Service (SaaS)
   - **Deployment Model:** Public Cloud
   - **Justification:** Canva allows users to create visual assets using pre-built graphic design tools and templates in the cloud. It runs as a managed software application available publicly over the internet to subscribers.

3. **AWS Educate**
   - **Service Model:** Infrastructure as a Service (IaaS) / Platform as a Service (PaaS)
   - **Deployment Model:** Public Cloud
   - **Justification:** It gives students direct access to cloud infrastructure, virtual environments, and deployment services hosted on Amazon's public cloud environment to learn cloud architectures.

## Git & GitHub for Cloud Projects

Version control is an indispensable tool when working with modern cloud infrastructure and collaborative software projects. In cloud environments where infrastructure is often managed as code (IaC), version control systems like Git allow development teams to record every modification, track configuration updates, and reverse unwanted changes seamlessly.

GitHub enhances collaboration across distributed teams by serving as a centralized workspace. It provides essential features such as branching, pull requests, and code reviews, enabling team members to experiment with new cloud architecture setups independently without disrupting the main production environment. Furthermore, tracking commits ensures complete auditability, reducing human errors, enhancing security compliance, and speeding up deployment pipelines across shared cloud environments.
